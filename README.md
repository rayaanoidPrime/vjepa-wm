# GrandTour JEPA World Model — jepa-wms implementation (exp-v2)

Action-conditioned **JEPA world model** for the ANYmal-D quadruped on the
**GrandTour** dataset, built on `facebookresearch/jepa-wms`
(frozen DINOv2 encoder + AdaLN action-conditioned predictor + rollout training).

This branch (`exp-v2`) is the second-generation pipeline. It implements the
guide in `docs/AGENTS.md` using the **primary recipe** (`jepa-wms` +
`franka_custom`-style episode data), as an alternative to the vjepa2-based
pipeline on `main`.

## What is in this repo

| Path | Purpose |
|---|---|
| `setup.sh` | One-shot environment setup (below) |
| `requirements.in` | Curated python deps installed into the venv |
| `grandtour/patches/` | Patch that adds the GrandTour dataset class + configs to a pinned `jepa-wms` checkout |
| `grandtour/scripts/` | Data download / episode build / eval / visualization scripts |
| `grandtour/env.sh` | Exports `JEPAWM_*`/`GT_*` environment variables (auto-generated by `setup.sh`) |
| `docs/DATA_SCHEMA.md` | The GrandTour episode `.h5` schema + sensor verification notes |
| `docs/EXPERIMENTS.md` | Run log of the validation experiment + results |

The actual training framework is **not vendored**. `setup.sh` clones
`facebookresearch/jepa-wms` at a pinned commit and applies our patch, so the
checkout stays diff-able against upstream.

## Quickstart

```bash
# 0) prerequisites: python >= 3.10 tooling via `uv` (installs itself if missing), a CUDA GPU
git clone git@github.com:rayaanoidPrime/vjepa-wm.git
cd vjepa-wm
git checkout exp-v2

# 1) environment (py3.10 venv + patched jepa-wms checkout + curated deps)
bash setup.sh
source grandtour/env.sh          # sets JEPAWM_HOME/DSET/LOGS, GT_RAW, TORCH_HOME

# 2) data: download a few GrandTour missions (HuggingFace/Zarr path)
python grandtour/scripts/download_missions.py \
    --missions 2024-10-01-11-29-55 2024-10-01-11-47-44

# 3) convert each mission into a jepa-wms episode.h5 (frames + per-frame
#    commanded twist, joint state, base pose)
python grandtour/scripts/build_episodes.py \
    --missions 2024-10-01-11-29-55 2024-10-01-11-47-44
#    (omit --missions to convert every mission present under $GT_RAW)

# 4) train the world model (see configs in the patched checkout)
#    single-GPU smoke first, then the real run
python "$JEPAWM_HOME/../.venv/bin/python" -m app.main \
    --fname configs/vjepa_wm/grandtour_sweep/gt_v0_SMOKE.yaml --debug
```

## The two-phase experiment (what this branch validates)

1. **World model** (frozen DINOv2 `vits14` encoder + AdaLN depth-6 predictor,
   12-frame windows @ 5 fps, 2-step rollout training, actions = commanded
   twist + normalized joints = 39-d).
2. **Decoder head** (in-domain ViT decoder trained as an autoencoder on the
   frozen encoder features, then used to visualize rolled-out future frames).

Numbers from the validation run are in `docs/EXPERIMENTS.md`; the copy-baseline
and visualization scripts under `grandtour/scripts/` reproduce them.

## How the pieces map to the guide

| Guide (AGENTS.md) item | Implementation |
|---|---|
| Primary recipe | `facebookresearch/jepa-wms` pinned + patched |
| Dataset | `grandtour/scripts/build_episodes.py` -> per-mission `episode.h5` (schema in `docs/DATA_SCHEMA.md`) |
| New dataset class | `jepa-wms/app/plan_common/datasets/grandtour_dset.py` (added by patch) |
| Config | `jepa-wms/configs/vjepa_wm/grandtour_sweep/gt_v0_*.yaml` (added by patch) |
| Training | `python -m app.main --fname <cfg> --debug` (see README there) |
| Eval (copy baseline) | `grandtour/scripts/eval_copy_baseline.py` (set `GT_RUN` to eval a scaled run) |
| Counterfactual action eval (guide item 9) | `grandtour/scripts/eval_counterfactual.py` |
| Action-rollout GIF/MP4s (final) | `grandtour/scripts/viz_action_rollout.py` (GT-action-conditioned or scripted plans, decoded with the published vm2m decoder) |
